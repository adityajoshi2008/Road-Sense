# Road-Sense
RoadSense is an AI-powered road safety and traffic monitoring system that uses computer vision and machine learning to detect road accidents, obstacles, potholes, lane paths, and other traffic-related hazards in real time. The system analyzes camera or dashcam footage to provide timely alerts and actionable insights, helping improve road safety .

## Features

- Road safety monitoring
- Detection of potential road hazards
- Accident or incident analysis
- Simple and efficient C-based implementation
- Easy-to-understand project structure

## Technologies Used

- C Programming Language
- GCC Compiler
- Git and GitHub

## Requirements

Before running this project, install:

- GCC compiler
- Git
- A C-compatible code editor or IDE

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/roadsense.git
```

Open the project folder:

```bash
cd roadsense
```

## Compilation

Compile the program using GCC:

```bash
gcc main.c -o roadsense
```

## Running the Program

On Linux or macOS:

```bash
./roadsense
```

On Windows:

```bash
roadsense.exe
```
